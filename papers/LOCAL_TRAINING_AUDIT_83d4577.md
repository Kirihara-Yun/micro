# 首轮单卡训练审查

2026-11-23。审查远端提交 `83d4577`。原始报告和日志在 [实验目录](../experiments/research_composed_operators/REPORT.md)。本地结论是撤回该轮的语言建模和解码比较。当前无法据此判断双阶段结构的效果。

| 问题 | 源码和影响 |
|---|---|
| 训练与验证泄漏未来 token | `model.py` 的 attention 没有因果 mask，同时没有位置编码。训练和验证使用整段 token，logits 左移一位对齐标签。输出位置 t 可以直接关注目标 token t+1。所有架构共用这条代码，排名也可能随未来信息利用能力而改变 |
| MoE 实际计算不同 | StandardMoEFFN 用被选专家概率缩放所有专家，再对专家轴求和。注释中提到的 mask 没有执行。等式实际是 `p_top1 * Σ_e E_e(x)`，而目标是 `p_top1 * E_top1(x)`。多算专家改变了模型输出及梯度 |
| 解码缺少 KV cache | 每生成一个 token 就把增长后的完整序列传给模型，测到的是逐步重算全历史的延迟，而且各 prompt 随机。P50 的倒数也不等于实际平均生成吞吐。可以保留日志作为当前脚本的耗时 |
| 成本公式有误 | 条件层应每阶段计 `G*r*r` 个所选权重，仓库用了 `2*r*r`。按 8 组、r=48，FFN 不含路由的 BF16 理论权重需求为 884736 / 921600 / 958464 B（MoE / 单 / 双）。计入各自全量路由投影则为 890880 / 1019904 / 1155072 B。原始 MoE 实现读取全部专家，前述 MoE 理论值只适用于正确 top-1；这些数字也都不代表实际 DRAM bytes。模型 FLOPs 比较还应计入 attention 的序列交互和 50257×384 的输出投影，不能沿用“3.5×整模型训练 FLOPs” |
| 续跑和末点口径 | 从 45.023M checkpoint 开始，重新初始化 AdamW 和数据 RNG，学习率随后固定为低值，同一采样 seed 会重放开头的数据。前段结束在 49.971M，续跑结束在 99.975M，均未触发各自目标点的验证。95.027M 最后一组验证为 4.904014 / 5.158465 / 5.214254，但属于有未来信息的目标。训练池只有约 57.08M tokens，训练步按序列有放回采样，应以处理量报告，无法解释为 100M 不重复数据 |
| 初始化和路由机制 | 方案提出近单位初始化。报告使用两个小随机矩阵，且将两个 top-1 概率相乘式地压在双阶段路径上。它可能压低输出/梯度，值得在正确的模型上测残差分支尺度和梯度。现有代码的负载均衡字段未接入 loss，报告也没有真实路由分布，无法判断是否塌缩 |

原始校准 CSV 重算后三组最后 50 步的平均吞吐为 76356 / 50537 / 42757 tokens/s。可用它们了解旧程序大致耗时。正式 50M 分支最后 50 步则为 75852 / 64723 / 47321 tokens/s，因此 15% 的训练差只适用于校准口径。总耗时应直接读取 wall time 或在后续显式做 CUDA 同步测量。

## 本地参考实现与交接

已用本地 PyTorch CPU 运行检查。只改后缀时，旧 MoE、单阶段、双阶段的前缀 logit 最大变化分别为 0.382、0.272 和 0.462。修改未选专家使历史 MoE 的输出变化约 0.00104。修正参考实现全部通过，并各执行两次优化器更新。另以相同随机输入探测默认初始化，单阶段与双阶段的分支输出 RMS 分别为 5.30e-4 和 8.88e-6，相差约 60 倍。这是初始化时的单点观测，无法归因为训练曲线差异。

在实验目录运行 `python audit_protocol.py`。这会检查改变后缀时原模型前缀 logits 会变化，修改未选专家权重时旧 MoE 输出会变化。新写的 `causal_reference.py` 加入因果 mask、位置编码和真实 top-1 参考执行。脚本同时检查修正后的前缀不变性、未选专家隔离、各路由梯度、有限的训练 loss，以及短训练循环。原始训练入口仍对应历史结果。参考 MoE 中逐专家的 Python 循环用于正确性，CUDA 高效实现和 KV cache 仍需独立写好并验证。

后续由本地实现训练与 decode 的下一版，再交给 WorkBuddy 跑 A100。先验证同一预算下中断续跑与连续训练一致、评估只依赖可见前缀、增量 decode 与同模型完整因果前向一致。待本地端到端 smoke 通过后，远端先只复跑小预算三组曲线。结构层面的直接对照包括单阶段、双阶段等尺度初始化，以及等预算的无交换双阶段。直到修正后的质量曲线出现证据，再扩大 BTT-MoE 和多种子训练。
